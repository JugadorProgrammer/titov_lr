# titov_lr

Учебный проект для выполнения лабораторных работ по Git и CI/CD.

## Возможности

Программа реализует арифметические операции:
- Сложение
- Вычитание
- Умножение
- Деление
- Возведение в квадрат
- Возведение в куб

## Запуск

python3 -B main.py

## Тестирование

python3 -B -m unittest discover -p 'test_*.py'

## CI/CD

GitHub Actions автоматически запускает тесты при push и pull_request.

Документация Python-модуля operations.py автоматически генерируется с помощью pydoc и сохраняется как артефакт GitHub Actions.
